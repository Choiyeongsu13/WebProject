================================================================================
 PortfolioBlog — 화면(UI)만 있는 프로젝트
================================================================================

 이 프로젝트에는 화면만 들어 있습니다.
 DAO · DTO · Service · Controller 는 직접 만드실 부분이라 넣지 않았습니다.


--------------------------------------------------------------------------------
 1. 이클립스에 넣기
--------------------------------------------------------------------------------

 File > Import > General > Existing Projects into Workspace
   -> Select root directory 로 압축을 푼 PortfolioBlog 폴더를 고릅니다.

 넣은 뒤 확인할 것

   가) WEB-INF/lib 에 JAR 넣기
       WEB-INF/lib/여기에_JAR_넣으세요.txt 를 읽어 주세요.
       JSTL 4개 (주신 exSample 프로젝트에 이미 있습니다) + ojdbc8.jar

   나) 톰캣 9 서버 연결
       프로젝트 우클릭 > Properties > Targeted Runtimes 에서 Apache Tomcat v9.0 체크

   다) 컴파일 레벨
       JavaSE-1.8 로 맞춰 두었습니다.
       Properties > Java Compiler 에서 1.8 인지 확인하세요.

   라) 실행
       프로젝트 우클릭 > Run As > Run on Server
       주소는 http://localhost:8080/PortfolioBlog/

 3. 언어 전환 (KO / JP) 이 돌아가는 방식
--------------------------------------------------------------------------------

 스크립틀릿을 안 쓰기 위해 JSTL 의 표준 방식인 properties 파일을 씁니다.

   common/lang.jsp 가 하는 일
     1. 주소에 ?lang=ja 가 붙어 오면 세션에 기억
     2. 기억된 값이 없으면 ko
     3. <fmt:setLocale> + <fmt:setBundle basename="message"> 로 그 언어 파일을 붙임

   화면에서 글자 꺼내기
     <fmt:message key="nav.home" />

 글자를 고칠 때는 message_ko.properties 와 message_ja.properties 를
 같이 손보세요. 한쪽에만 있으면 그 언어에서 ???nav.home??? 처럼 나옵니다.

 한글이 \uXXXX 로 적혀 있는 이유는 properties 파일 안에 적어 두었습니다.
 이클립스에서 이 파일을 열면 한글로 보이고, 한글로 입력하면 저장할 때
 알아서 \uXXXX 로 바꿔 줍니다.

 4. DAO 를 붙일 자리
--------------------------------------------------------------------------------

 지금은 화면에 예시 내용이 그대로 적혀 있습니다.
 서블릿을 붙이면 그 자리를 반복문으로 바꾸시면 됩니다.

 각 JSP 안에 [연결 지점] 이라고 적어 둔 주석이 있습니다. 거기가 그 자리입니다.

 예를 들어 posts.jsp 의 글 목록은

     <a class="postrow" href="...">
         <span class="post-title">JSP 프로젝트에서 DAO 패턴 정리하기</span>
         ...
     </a>

 이렇게 손으로 적혀 있는데, 컨트롤러에서

     request.setAttribute("posts", dao.selectList());

 로 넘겨 주면 화면은 이렇게 바뀝니다.

     <c:forEach var="p" items="${posts}">
         <a class="postrow" href="post.jsp?id=${p.postId}">
             <span class="post-title"><c:out value="${p.title}" /></span>
             ...
         </a>
     </c:forEach>

 사용자가 입력한 값(제목, 댓글 내용, 닉네임 등)은 반드시 <c:out> 으로 감싸세요.
 그냥 ${p.title} 로 두면 누가 제목에 <script> 를 넣었을 때 그대로 실행됩니다.

 5. 아직 안 되는 것 (화면만 있어서)
--------------------------------------------------------------------------------

   - 로그인 : admin/login.jsp 는 모양만 있습니다. 눌러도 아무 일이 없습니다.
   - 글쓰기 : admin/write.jsp 의 form action 이 # 입니다.
   - 댓글   : 남기기 · 삭제 버튼이 동작하지 않습니다.
   - 목록   : 전부 예시 내용입니다. DB 를 보지 않습니다.

   그리고 admin/write.jsp 는 지금 주소를 직접 치면 그냥 열립니다.
   헤더에서 글쓰기 버튼을 숨기는 것만으로는 못 막습니다.
   컨트롤러나 필터에서 세션을 확인해 막아 주세요.
